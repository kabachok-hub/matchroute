# MatchRoute для Windows

<img src="docs/img/matchroute-avatar.png" alt="Аватар MatchRoute" width="144">

MatchRoute помогает проверить и обработать игровой UDP-трафик Fortnite, если соединение с сервером матча замирает. Основной режим использует адаптер Wintun и отправляет пакеты через выбранное сетевое подключение. Дополнительные VPN-профили управляются во вкладке «Подключения».

Это самостоятельная Windows-версия на основе [fnport](https://github.com/YUNGSLXRD/fnport) от YUNGSLXRD, базовый коммит [5fa4656](https://github.com/YUNGSLXRD/fnport/commit/5fa4656b9d8e8c86dc06bdde83be6fedf8356337). Проект не связан с Epic Games.

## Запуск

1. Скачайте **MatchRoute-v…-windows-x64-setup.exe** со [страницы релизов](https://github.com/kabachok-hub/matchroute/releases) и запустите установщик.
2. Откройте **MatchRoute** из меню «Пуск». Права администратора нужны для работы виртуального адаптера и изменения маршрутов.
3. Для проверки прямого режима выключите другие VPN и оставьте «Подключения» в положении «Выключено».
4. Откройте «Настройки» → «Проверка провайдера» → «Проверить». Если появилась рекомендация, примените её.
5. Во вкладке «Обзор» нажмите «Включить» и проверьте вход в матч. Состояние игрового потока видно во вкладке «Сеансы».

Проверка провайдера измеряет ответы маяков Epic. Вход в реальный матч зависит от сети, игрового сервера и причины сбоя.

Если на GitHub есть более новый выпуск с установщиком для Windows x64, в верхней части окна появится кнопка «Скачать обновление». Она откроет загрузку установщика в браузере.

## Автозапуск

В установленной версии откройте «Настройки» → «Автозапуск и автовключение» → «Включить автозапуск». При следующем входе в Windows MatchRoute запустится в трее и включит обработку трафика с сохранёнными настройками. Опция выключена по умолчанию. Повторное нажатие «Отключить автозапуск» удаляет задачу Windows.

Автозапуск доступен при установке в стандартную папку `Program Files\MatchRoute`. Задача привязана к учётной записи, из которой вы включили настройку. Удаление приложения снимает автозапуск.

## Проверка архива и сборка

Сравните SHA-256 установщика с файлом **SHA256SUMS.txt** из того же релиза. Установщик и MatchRoute не имеют подписи Authenticode. Wintun поставляется с подписью WireGuard LLC и сверяется с официальным архивом при сборке.

Для сборки из исходников на Windows x64 нужны PowerShell 7, Go 1.26.10 и NSIS 3.13. Команды `go` и `makensis` должны быть доступны в `PATH`.

```powershell
pwsh -File windows/build-matchroute.ps1 -Version v0.1.3
```

Скрипт проверяет хеши сторонних архивов, собирает sing-box из зафиксированной ревизии, запускает проверки Go и создаёт установщик и файл контрольной суммы в **windows/dist**.
